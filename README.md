Nuestra Biografía en la Web
Descripción

Este proyecto consiste en el desarrollo de un sitio web estático creado como parte del Laboratorio N.º 1 de Ingeniería Web de la Universidad Tecnológica de Panamá.

El sitio presenta información personal, académica, hobbies, intereses y metas futuras de los integrantes del equipo, utilizando HTML5 y CSS3.
